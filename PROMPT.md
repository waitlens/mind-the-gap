Build a complete, playable single-page three.js first-person horror/exploration web game in the current directory: "Mind the Gap" — the London Underground Backrooms.

Concept: the player is stuck in an endless, procedurally looping London Underground station after the last train. Corridors, tiled tunnels, escalators/stairs, platforms and cross-passages repeat and subtly go wrong (station names that don't exist, roundel signs slightly off, announcements that get stranger, platform clocks running backwards). Goal: find the exit by reading signs and listening to announcements; a few rare clues lead to the "Way Out". Keep it eerie, not gory.

Hard requirements:
1. VERY faithful London Underground look. FIRST use web search / web fetch to research reference imagery and descriptions: deep-level tube platform tunnels (curved tiled walls, cream/coloured tile bands like Leslie Green / Holden stations), roundel name boards, "Way Out" yellow-on-black / white-on-blue signs, "Mind the gap" platform-edge markings, tactile paving, wooden/metal escalators with adverts on the side walls, poster frames, dot-matrix next-train indicators, line colours (Central red, Northern black, Piccadilly blue, etc.), bench styles, cross-passages. Write a short REFERENCES.md listing what you learned and the URLs. Do NOT hotlink or copy copyrighted photos into the game; recreate everything procedurally (canvas-generated textures for tiles, signs, posters, roundels). Use a freely-licensed font similar to Johnston (e.g. a Google Font loaded locally via npm @fontsource or system sans fallback); do not ship the proprietary Johnston font.
2. Visual style: retro camcorder / DV tape look as a post-processing pass: low-res render scaled up, chromatic aberration, scanlines, noise/grain, slight barrel distortion, VHS tracking wobble occasionally, slightly crushed colour, a "REC ●" indicator and a running timestamp overlay in the corner (DV style date like NOV 17 2026), handheld camera bob. Fluorescent-light flicker.
3. Audio via WebAudio procedurally: fluorescent hum, distant train rumble, wind through tunnels, footsteps on tile, and "Mind the gap" style announcement chimes (use speechSynthesis for announcements if available, with a British English voice, falling back silently).
4. Controls: desktop WASD + mouse look with pointer lock, Shift to run, E to interact/read. Mobile: on-screen virtual joystick (left) + drag-to-look (right) + interact button, responsive layout, works in portrait and landscape on phones. Must perform OK on a phone: keep draw calls low, use instancing/merged geometry, render at low internal resolution (fits the DV look anyway).
5. Procedural endless layout built from modular segments (corridor, bend, stairs/escalator, platform, cross-passage, junction), generated as the player moves and culled behind them.
6. Title screen, a win condition (finding the true exit after following clues), and a short end screen.
7. Use Vite + three (npm). Vite base must be './' so the built dist/ works when hosted at a subpath on GitHub Pages. `npm run build` must succeed.
8. Write GAME.md describing controls and how to win. Add a smoke test script tests/smoke.mjs if practical (headless check that the page loads without console errors), but don't spend long on it.
9. Expose window.__game with start() and a state object for automated testing.

Work autonomously until the game is complete and builds. Don't use git commands (I'll commit). When done, print a short summary of what you built.
